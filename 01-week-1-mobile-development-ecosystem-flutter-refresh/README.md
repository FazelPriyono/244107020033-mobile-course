## Refleksi

### 1. Kapan native lebih tepat dipilih daripada cross-platform?

Native lebih tepat digunakan ketika aplikasi membutuhkan performa maksimal, akses khusus terhadap fitur perangkat, atau integrasi yang sangat spesifik dengan Android maupun iOS. Cross-platform seperti Flutter lebih cocok jika ingin membuat aplikasi untuk beberapa platform dengan satu basis kode sehingga pengembangan menjadi lebih cepat dan efisien.

### 2. Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?

State menentukan kondisi atau data yang ditampilkan oleh aplikasi. Ketika state berubah, Flutter akan membangun kembali widget yang terdampak sehingga UI menyesuaikan dengan state terbaru. Hal ini merupakan penerapan UI deklaratif karena developer menentukan tampilan berdasarkan kondisi state, bukan mengubah tampilan secara manual.

### 3. Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?

Commit kecil dan memiliki pesan yang jelas membuat perubahan lebih mudah dilacak, dipahami, dan diperbaiki. Dalam kerja tim, hal ini memudahkan proses review dan kolaborasi. Untuk portfolio, riwayat commit yang rapi juga menunjukkan bahwa proses pengembangan dilakukan secara terstruktur dan profesional.
